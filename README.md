## 🚀 Featured Projects

### 1. 🔗 [CyberSecurity Project](https://github.com/rajtalukder159/CyberSecurity-Project)
A structured cybersecurity learning portfolio with hands-on labs across several domains.
- **Structure:** Lab Setup → Reconnaissance → Assessment → Exploitation → Web & System Security → Cloud & Forensics → Governance & Compliance
- **Tools:** Metasploit, Burp Suite, OWASP ZAP, SQLMap, LazyS3, VirusTotal, Detect It Easy (DIE), Wireshark, OpenVAS, Nessus
- **Skills shown:** Vulnerability assessment, exploitation, web and network attacks, malware analysis, cloud enumeration, security audit lifecycle

### 2. 🐳 [Docker-based Debian Lab](https://github.com/rajtalukder159/docker-debian-lab)
A two-part lab using Docker and Debian to practice red team scenarios.
- **Part 1, building the target:** Docker basics, pulling the Debian image, running containers, Apache setup, port mapping, ServerName fixes (with screenshots)
- **Part 2, enumeration and testing:** Kali Linux, Nmap and Nikto, scanning methodology, findings (directory listing, server version disclosure, missing security headers), lessons learned and best practices

### 3. 💻 [DSA-Practice-GeeksforGeeks](https://github.com/rajtalukder159/DSA-Practice-GeeksforGeeks)
Data Structures &amp; Algorithms problems and solutions for practice.
- **Topics:** Arrays, strings, linked lists, stacks and queues, trees, binary search, sorting, recursion and backtracking, graphs, dynamic programming
- **Tech stack:** Python, C, JavaScript
